# Fees

| Treatment | Price |
|---|---|
| Consultation | ₹500 |
| Check-up and cleaning | ₹1,500 |
| Tooth-coloured filling | from ₹1,200 per tooth |
| Root canal treatment | from ₹6,000 per tooth (crown extra) |
| Ceramic crown | from ₹8,000 |
| Simple extraction | ₹1,500 |
| Wisdom tooth extraction | from ₹4,000 |
| Teeth whitening (in clinic) | ₹8,000 |
| Braces or aligners consultation | free |

The dentist gives a written estimate before any treatment over ₹5,000.
