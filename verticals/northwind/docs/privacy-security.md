# Privacy and account security

We only use your personal data to process orders, provide support and, if you opt in, send
marketing emails. You can unsubscribe from marketing at any time using the link in any email.
Northwind Goods will never ask for your password, OTP, full card number, CVV or UPI PIN. If someone
asks for these while claiming to be from Northwind Goods, do not share them.
