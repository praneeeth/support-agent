# Security deposit and token amount

- In Pune, owners usually ask for a security deposit of 2 to 3 months' rent. The owner sets it.
- A token amount (usually ₹10,000 to ₹25,000) reserves a home once the owner accepts your offer.
  It is adjusted against the deposit.
- The deposit is refunded when you move out, minus any agreed deductions for damage.
