# Discount codes and offers

- Only one discount code can be used per order.
- Codes must be applied at checkout and cannot be added after an order is placed.
- Discount codes do not apply to gift cards.
- New customers can use WELCOME10 for 10% off their first order, up to a maximum discount of ₹500.
- If a code is not working, check its expiry date and minimum order value in the offer terms.
